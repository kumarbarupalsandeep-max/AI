## Study advice

1. Official documentation ko primary technical reference banayein.
2. Concept padhne ke baad small coding example karein.
3. Model ke claims ko test data aur reliable evaluation se verify karein.
4. Privacy, security, copyright aur licensing ko project ke start se consider karein.
