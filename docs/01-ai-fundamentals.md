## 1. AI kya hai?

AI ka full form Artificial Intelligence hai. Hindi mein ise Kritrim Buddhimatta kehte hain. Simple words mein, AI Computer Science ki aisi field hai jisme systems language samajhne, images pehchanne, patterns dhoondhne, predictions karne, content generate karne aur decisions mein madad jaise tasks kar saken.

AI insaan ki tarah conscious ya human nahi hota. AI systems data, algorithms, models aur computing resources ki madad se specific tasks perform karte hain.

### Everyday examples

- Email spam detection.
- Maps mein route aur traffic prediction.
- Online shopping recommendations.
- Voice assistants aur speech-to-text.
- Image recognition.
- Chatbots aur coding assistants.
- Fraud aur unusual activity detection.

Timeline simplified hai; AI research ka development in dates ke beech bhi continuously hota raha.

## 3. AI ke types

AI ko classify karne ke multiple tareeke hain.

### 3.1 Capability ke basis par

**Narrow AI (ANI):** Ek defined task ya limited range of tasks ke liye banaya gaya AI. Aaj ke practical AI products mostly isi category mein aate hain. Examples: spam filters, recommendation systems, image classifiers aur language assistants.

**Artificial General Intelligence (AGI):** Aisi hypothetical capability jisme system bahut alag-alag domains mein broad, flexible learning aur problem-solving kar sake. AGI ki accepted, universally agreed definition aur test abhi settled nahi hain. Is level ko achieved fact nahi samajhna chahiye.

**Artificial Superintelligence (ASI):** Hypothetical concept jahan AI broad intellectual tasks mein human capabilities se kaafi aage ho. Ye theoretical/future concept hai.

### 3.2 Technology / approach ke basis par

| Approach | Kaise kaam karta hai | Example |
|---|---|---|
| Rule-Based System | Human-written IF/THEN rules follow karta hai | Fixed eligibility rules |
| Machine Learning | Data se patterns learn karta hai | Spam classification |
| Deep Learning | Multi-layer neural networks use karta hai | Image recognition |
| Generative AI | Learned patterns se new content generate karta hai | Text/image generation |
| Agentic AI | Goal ke liye tools aur multiple steps use kar sakta hai | Research workflow agent |

Ye categories ek doosre ke alternatives hi nahi hain. Generative AI aksar deep learning par based hota hai; AI agent ek ya multiple models aur external tools use kar sakta hai.

## 4. Traditional Software vs Machine Learning

### Traditional software

Programmer explicit rules likhta hai. Input rules se process hota hai aur output milta hai.

Example: Agar temperature 30°C se zyada ho to cooling system ON kar do.

### Machine Learning system

Training examples diye jaate hain. Learning algorithm data se model parameters learn karta hai. Trained model naye input par prediction karta hai.

Example: Past usage, temperature aur occupancy data se cooling demand estimate karna.

**Important:** Machine Learning software bhi normal code se build hota hai. Difference ye hai ki behaviour ka kuch hissa manually written rules ke bajay learned model parameters se aata hai.

## 5. AI / ML workflow

1. **Problem definition:** Decide karein system ko kaunsi problem solve karni hai.
2. **Data collection:** Relevant data gather karein; permission, quality aur privacy ka dhyan rakhein.
3. **Data cleaning:** Missing, duplicate, inconsistent aur incorrect values handle karein.
4. **Data preparation:** Features, labels aur train/validation/test splits prepare karein.
5. **Model selection:** Problem aur data ke hisaab se algorithm/model choose karein.
6. **Training:** Training data se model parameters learn karwayein.
7. **Evaluation:** Unseen data par performance aur errors measure karein.
8. **Deployment:** Model ko application, API ya service ke through users tak pahunchayein.
9. **Monitoring:** Accuracy, latency, cost, failures, drift aur safety issues monitor karein.
10. **Improvement:** Feedback aur new data ke basis par controlled updates karein.

## 7. AI ke major application areas

- **Healthcare:** Medical image support, research assistance, administrative workflows. Clinical decisions ke liye expert oversight zaroori hai.
- **Banking & Finance:** Fraud detection, risk analysis aur customer support.
- **Cybersecurity:** Suspicious behaviour detection, alert prioritization aur security analysis.
- **Software Development:** Code suggestions, test generation, documentation aur debugging assistance.
- **Education:** Learning support, practice questions aur content adaptation.
- **E-commerce:** Recommendations, search relevance aur support automation.
- **Manufacturing:** Quality inspection aur predictive maintenance.
- **Transport:** Route estimation, fleet planning aur driver-assistance systems.

## 8. AI ki limitations aur risks

1. **Hallucination:** Generative model plausible lekin galat jawab de sakta hai.
2. **Bias:** Training data ya system design mein bias output ko unfair bana sakta hai.
3. **Privacy:** Sensitive data ka improper collection ya exposure risk create karta hai.
4. **Security:** Prompt injection, data leakage, model abuse aur insecure integrations ka risk hota hai.
5. **Reliability:** Performance new users, languages, locations ya conditions mein badal sakti hai.
6. **Cost and energy:** Large models ko train/serve karne mein expensive compute lag sakta hai.
7. **Copyright and licensing:** Training data, generated output, datasets aur third-party assets ke rights check karne hote hain.
8. **Human oversight:** High-impact decisions mein responsible human review aur appeal process zaroori ho sakte hain.

## 10. Chapter summary

- AI ek broad Computer Science field hai.
- Aaj ke deployed systems mostly Narrow AI hain.
- ML data se patterns learn karta hai.
- Deep Learning neural networks use karta hai.
- Generative AI content create kar sakta hai, lekin output verify karna chahiye.
- Production AI ke liye data, evaluation, security, deployment aur monitoring sab important hain.
